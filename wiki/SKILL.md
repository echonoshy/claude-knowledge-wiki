# 阅读方法

1. 从 [目录](_index.md) 的导航按问题选择入口。
2. `[source | as-of]` 里的文件链接打开该来源的索引页。定位信息是规范化文本行号或 PDF 页码，索引页同时提供原件。日期默认是申报日，财务期间单列。董事会演示稿使用材料日，另标明申报日。
3. `[[slug]]` 用于兼容原教程的 Wiki 链接。普通 Markdown 阅读器可从目录打开同名页面。
4. 金额带口径、日期、版本和单位。旧值保留结束时间，预测用 `E` 标记。`SYNTHETIC` 标记虚构样本。
5. 找不到答案时到 [疑点](escalations.md) 和 [补查记录](_build-report.md#补查结果) 查原因及需要的原件。
